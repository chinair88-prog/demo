<h2 id="access-statement">Access statement</h2>
<br />
<p>The platform does not expose a byte-for-byte export of the entire conversation transcript, hidden tool payloads, or private reasoning as a file. Therefore this review does not falsely claim a literal line-by-line export from the first UI character.</p>
<br />
<p>The review used:</p>
<br />
<p>- all user and assistant messages available in the active conversation context;</p>
<p>- the safe conversation summary available to the assistant;</p>
<p>- all generated conversation artifacts visible in <code class="code-inline">/mnt/data</code>;</p>
<p>- all final ZIPs, Markdown files, PDF, XLSX catalogue, manifests, release reports, and GitHub release markers available in this session.</p>
<br />
<h2 id="reconstructed-non-negotiable-intent">Reconstructed non-negotiable intent</h2>
<br />
<p>- The Handbook must be written in English; progress updates may be in Persian.</p>
<p>- The work documents the project; it does not fix application code.</p>
<p>- Repository executable source, migrations, runtime configuration, tests, and deployment evidence outrank plans and READMEs.</p>
<p>- <code class="code-inline">Reality != Knowledge about Reality</code> is foundational.</p>
<p>- Recommendation, Decision, Intent, execution, and outcome remain separate.</p>
<p>- The three-Portal lifecycle and the complete global-trade flow must be covered.</p>
<p>- AI Orchestrator, AI Runtime, MCP, Workflow Engine, Event Bus, and Domain ownership must not be collapsed.</p>
<p>- AI must not write directly to Domain databases or create shadow truth.</p>
<p>- Every chapter should cover ownership, state, rules, Commands, Events, APIs, data, Portals, AI, security, reliability, tests, operations, examples, and repository evidence.</p>
<p>- Unverified behavior must never be presented as implemented.</p>
<p>- The final corpus should be exhaustive, but page count is not the completion criterion.</p>
<br />
<h2 id="review-conclusion">Review conclusion</h2>
<br />
<p>The direction and conceptual hierarchy remain correct. The content-maturity claims of Batches 02-06 were not correct and have been superseded by corrected <code class="code-inline">AUDITED-v2</code> packages.</p>
