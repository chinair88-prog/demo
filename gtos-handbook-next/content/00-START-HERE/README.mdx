<h2 id="final-edition-10">Final Edition 1.0</h2>
<br />
<p><strong>Global Trade Operating System - Enterprise Architecture, Domain Design, Implementation, Security, AI, Data, Delivery, and Operations Handbook</strong></p>
<br />
<p>This package is the normative design and implementation reference for building GTOS as a global, multi-tenant, event-driven, AI-native trade operating system.</p>
<br />
<p>The main book describes <strong>what GTOS shall become and how it shall be implemented</strong>. The current repository is not treated as the architecture authority. Repository findings are isolated under <code class="code-inline">08-CURRENT-PROJECT-GAP-ANALYSIS</code> and may be used only to plan migration toward the target architecture.</p>
<br />
<h2 id="start-here">Start here</h2>
<br />
<p>1. Read <code class="code-inline">PUBLICATION-STATEMENT.md</code>.</p>
<p>2. Read <code class="code-inline">MASTER-TABLE-OF-CONTENTS.md</code>.</p>
<p>3. Read the documents under <code class="code-inline">01-NORMATIVE-CORE</code> in numeric order.</p>
<p>4. Use <code class="code-inline">03-DETAILED-VOLUMES</code> as the comprehensive domain and platform reference.</p>
<p>5. Use <code class="code-inline">04-DELIVERY-PLAYBOOKS</code> to implement each vertical slice.</p>
<p>6. Use <code class="code-inline">06-CATALOGUES</code> and <code class="code-inline">09-BUILD-AND-VALIDATION</code> for navigation and conformance.</p>
<br />
<h2 id="edition-rule">Edition rule</h2>
<br />
<p>The words <strong>shall</strong>, <strong>must</strong>, and <strong>required</strong> are normative. <strong>Should</strong> identifies the default engineering choice unless an Architecture Decision Record authorizes an exception. <strong>May</strong> identifies an allowed option.</p>
<br />
<h2 id="primary-outcome">Primary outcome</h2>
<br />
<p>A team conforming to this handbook shall be able to design, implement, verify, deploy, operate, recover, audit, and evolve GTOS without relying on undocumented tribal knowledge.</p>
