# Output and Authority Matrix

| Output Type | Describes | Binding? | Minimum Metadata |
|---|---|---|---|
| Retrieval | existing source content | no | source, version, access context |
| Extraction | structured interpretation | no | source span, method, confidence |
| Inference | derived claim | no | premises, method, uncertainty |
| Prediction | possible future | no | horizon, model, calibration |
| Recommendation | proposed choice | no | evidence, alternatives, confidence |
| Decision | governed commitment | yes within scope | authority, evidence, policy, time |
| Intent | desired authorized effect | authorizes execution | objective, initiator, constraints |
| Execution Request | technical request under Intent | may cause effect | Intent, idempotency, target |
| Outcome | observed result | factual claim | source, time, evidence |
