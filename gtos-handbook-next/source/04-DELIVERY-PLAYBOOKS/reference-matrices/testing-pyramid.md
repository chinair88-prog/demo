# GTOS Verification Matrix

| Layer | Purpose | Examples |
|---|---|---|
| Definition | verify terms and ownership | glossary review, registry validation |
| Invariant | protect domain truth | property tests, state transition tests |
| Contract | protect exchange | API, Event, schema, consumer tests |
| Policy | protect authority | permission, obligation, delegation tests |
| Temporal | protect historical meaning | bitemporal and point-in-time tests |
| AI Evaluation | protect evidence and behavior | factuality, calibration, tool safety |
| Security | protect trust boundaries | threat tests, abuse cases, penetration |
| Resilience | protect service and truth | dependency failure, replay, recovery |
| Migration | protect continuity | reconciliation and semantic equivalence |
| Operational | protect production response | runbook and incident exercises |
