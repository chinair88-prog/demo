# Implementation Evidence Catalogue

## Architecture Evidence

- context and container diagrams;
- domain ownership map;
- command and event catalogues;
- state models and invariants;
- Canon traceability matrix;
- ADRs and exception records.

## Engineering Evidence

- schema validation;
- contract test reports;
- policy tests;
- migration tests;
- security scans;
- dependency and artifact provenance;
- resilience tests.

## Operational Evidence

- SLO reports;
- incident records;
- restoration tests;
- recovery reconciliation;
- access and decision audit;
- AI evaluation and drift reports;
- unresolved risk and exception register.

Evidence SHALL identify version, scope, owner, collection time, and integrity.
