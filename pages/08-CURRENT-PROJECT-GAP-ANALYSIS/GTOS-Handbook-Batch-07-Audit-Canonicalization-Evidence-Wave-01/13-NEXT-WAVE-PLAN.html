Wave 02 scope#

  1. Quality inspection and release;
  2. packing list and commercial invoice;
  3. export/import customs;
  4. shipping booking, tracking, and custody;
  5. warehouse receiving and inventory synchronization.

Wave method#

For each area:

  • inspect entity, repository, service, controller, DTO, migration, tests, frontend routes, deployment, and Events;
  • produce an implementation map;
  • classify each capability;
  • identify ownership conflicts and destructive-history patterns;
  • rewrite the corresponding skeleton chapters;
  • update traceability and the direct-read catalogue;
  • commit code-grounded chapters to the Handbook branch.
