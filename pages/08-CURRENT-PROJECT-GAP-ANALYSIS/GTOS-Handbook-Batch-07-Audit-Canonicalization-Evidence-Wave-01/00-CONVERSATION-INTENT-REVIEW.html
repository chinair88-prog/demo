Access statement#

The platform does not expose a byte-for-byte export of the entire conversation transcript, hidden tool payloads, or private reasoning as a file. Therefore this review does not falsely claim a literal line-by-line export from the first UI character.

The review used:

  • all user and assistant messages available in the active conversation context;
  • the safe conversation summary available to the assistant;
  • all generated conversation artifacts visible in /mnt/data;
  • all final ZIPs, Markdown files, PDF, XLSX catalogue, manifests, release reports, and GitHub release markers available in this session.

Reconstructed non-negotiable intent#

  • The Handbook must be written in English; progress updates may be in Persian.
  • The work documents the project; it does not fix application code.
  • Repository executable source, migrations, runtime configuration, tests, and deployment evidence outrank plans and READMEs.
  • Reality != Knowledge about Reality is foundational.
  • Recommendation, Decision, Intent, execution, and outcome remain separate.
  • The three-Portal lifecycle and the complete global-trade flow must be covered.
  • AI Orchestrator, AI Runtime, MCP, Workflow Engine, Event Bus, and Domain ownership must not be collapsed.
  • AI must not write directly to Domain databases or create shadow truth.
  • Every chapter should cover ownership, state, rules, Commands, Events, APIs, data, Portals, AI, security, reliability, tests, operations, examples, and repository evidence.
  • Unverified behavior must never be presented as implemented.
  • The final corpus should be exhaustive, but page count is not the completion criterion.

Review conclusion#

The direction and conceptual hierarchy remain correct. The content-maturity claims of Batches 02-06 were not correct and have been superseded by corrected AUDITED-v2 packages.
