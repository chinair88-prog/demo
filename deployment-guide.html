Deploying the GTOS Handbook Site

This package contains a dependency-free static documentation site. Extract the archive and publish the directory as-is.

Local preview

shell
./serve.sh
# or
python -m http.server 8080

Open http://localhost:8080. On Windows, run serve.bat.

Static hosting

  • GitHub Pages: upload the extracted directory to a Pages branch.
  • Netlify/Vercel: use the directory as the publish folder; no build command is required.
  • S3/CloudFront or compatible object storage: upload with index.html as the default document.
  • Nginx/Apache: serve files directly and enable compression for HTML, CSS, JS, JSON and SVG.

Package semantics

The .site file is a ZIP-compatible archive with a descriptive extension. It can be renamed to .zip or opened by any ZIP utility.

Integrity

Use SITE-SHA256SUMS.txt and SITE-INTEGRITY-REPORT.md to verify the publication.
