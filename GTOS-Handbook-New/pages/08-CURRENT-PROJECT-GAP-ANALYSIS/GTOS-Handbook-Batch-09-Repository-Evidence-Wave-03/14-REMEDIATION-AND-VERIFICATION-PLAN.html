14 — Remediation and Verification Plan


Priority 0 — Security and Commercial Integrity #


  • Fix Order list() tenant leak and all bulk operation leaks.
  • Scope Cart, Marketplace Catalog, Pricing, Fulfilment, Returns, Settlement, ESG and AI Evaluation ID lookups to trusted tenant context.
  • Stop accepting authoritative price, user, payment and verification state from Client input.
  • Disable or protect direct confirm-payment, direct product approval and self-verified catalog fields.
  • Correct Order history from/to status recording.
  • Replace random actor UUIDs in Returns with authenticated actor identity.
  • Require POD before Order becomes Delivered.

    • Priority 1 — Canonical Ownership #


  • Product Master versus Marketplace Catalog/Offer.
  • Price authority and immutable Price Version.
  • Customer Order versus Warehouse Fulfilment Order.
  • Marketplace settlement ledger versus Payment payout execution.
  • Compliance ESG versus specialized Carbon service.
  • Return disposition versus Inventory stock posting.

    • Priority 2 — Reliable Execution #


  • Transactional outbox/inbox for Order، Pick/Pack، Returns، Settlement و ESG.
  • Order Saga with inventory reservation, payment authorization, fulfilment creation and compensation.
  • Idempotent Checkout، Payment confirmation، Return receive/inspect and Settlement transaction ingestion.
  • Live carrier adapter، quote expiry، booking، tracking webhook and POD.
  • Immutable evidence journals instead of mutable JSON timelines.
  • Multi-currency normalization and financial reconciliation.

    • Required verification #


  • tenant isolation tests including list/bulk/cache paths؛
  • client price tampering E2E؛
  • duplicate checkout/payment webhook tests؛
  • order saga failure/compensation tests؛
  • concurrent stock allocation and over-pick tests؛
  • return quantity discrepancy and duplicate restock tests؛
  • settlement cross-tenant/currency/provider reconciliation؛
  • ESG methodology/version/assurance tests؛
  • AI evaluation run ownership, score range and duplicate-review tests؛
  • CI logs and migration upgrade evidence.
